# Typical Amazon Ads API users are advertising solution providers, agencies with internal engineering resources managing significant campaign volume, and advertisers with internal engineering resources running a significant volume of Amazon Ads campaigns. The Amazon Ads API requires an application and approval process before access is granted. Businesses that build applications and software solutions to automate and help optimize advertising on behalf of others can access the Amazon Ads API as a third party and license their application to others. Direct advertisers can request registration to access the Amazon Ads API on behalf of their own advertising account to automate, scale, and optimize advertising activities and reporting. Developers building applications with the Amazon Ads API should apply for access; advertisers using a third-party tool that uses the API do not need to request API access.
