# Campaigns can now be managed across ad products using a common model and a single set of API endpoints. The new cross-ad-product campaign management capabilities are part of the Amazon Ads API v1. The Amazon Ads API can also be used to create and manage sponsored ads and Amazon DSP campaigns.

## Details

Campaigns can now be managed across ad products using a common model and a single set of API endpoints. The new cross-ad-product campaign management capabilities are part of the Amazon Ads API v1. The Amazon Ads API can also be used to create and manage sponsored ads and Amazon DSP campaigns.
